# AULA F-цуврал — Монгол хэлний багц

AULA F65 / F75 / F99 / F108 гарын **Windows драйверыг монгол хэл дээр**
ажиллуулах хэлний багц.

Драйверын программыг (`OemDrv.exe`) **өөрчлөхгүй**. Энэ драйвер өөрөө хэлний
файлаа гаднаас уншдаг тул зөвхөн шинэ хэл нэмж өгч байгаа хэрэг — AULA-гийн
өөрийнх нь дэмждэг арга.

> Хамаарах: [WIN 60/68 HE веб драйверын монгол хувилбар](https://kizaialt.github.io/winhe-driver/).
> Нэр томьёог хоёуланд нь ижил байлгасан.

---

## Яагаад энэ арга вэ

Драйверыг задалж үзэхэд бүтэц нь ийм байв:

```
app\Cfg.ini              Lang1=English,en
                         Lang2=简体中文,sc
                         Lang3=한국어,Korean      ← хэлний жагсаалт
app\Text\en\text.xml     англи мөрүүд
app\Text\sc\text.xml     хятад мөрүүд
app\Text\Korean\text.xml солонгос мөрүүд
app\OemDrv.exe           программ өөрөө
```

`OemDrv.exe` дотор `Lang%d`, `Lang%d is invalidate`, `Text\`, `\text.xml`
гэсэн мөрүүд байна — өөрөөр хэлбэл программ нь `Cfg.ini`-ээс хэлний
жагсаалтыг уншиж, харгалзах `Text\<хавтас>\text.xml`-ийг ачаалдаг.

Тиймээс монгол хэл нэмэх нь:

1. `Cfg.ini` дотор `Lang4=Монгол,mn` мөр нэмэх
2. `app\Text\mn\text.xml` файл үүсгэх

**Хоёулаа энгийн текст файл.** Программын exe хөндөгдөхгүй тул:

- Windows SmartScreen / антивирус асуудал үүсэхгүй
- AULA шинэ драйвер гаргахад хэлний файлыг дахин үүсгэхэд л хангалттай
- Хэрэглэгч AULA-гийн жинхэнэ драйверыг суулгана

## Дэмжигдэх загварууд

| Загвар | Мөрийн тоо | Багц |
|---|---|---|
| AULA F65 | 231 | `dist/AULA_F65_driver_mn.zip` |
| AULA F75 | 287 | `dist/AULA_F75_driver_mn.zip` |
| AULA F99 | 231 | `dist/AULA_F99_driver_mn.zip` |
| AULA F108 | 232 | `dist/AULA_F108_driver_mn.zip` |

Дөрвүүлээ ижил программ (`BYCOMBO4` / `OemDrv.exe`) дээр суурилсан тул
нийт **282 өвөрмөц мөр** орчуулахад хангалттай байсан. Загвар бүрийн
`text.xml` нь тухайн загварын түлхүүрүүдээр яг таарч үүсгэгдэнэ.

### Хамрагдаагүй загварууд

| Загвар | Шалтгаан |

| **F87 / F87 Pro** | Өөр багц (NSIS, 13.8 МБ) — тусад нь шалгах шаардлагатай |
| F68, F98X, F99MAX | Өөр багц (Qt5 / 33–103 МБ) |
| **F87 PRO V2, F108 PRO V2** | AULA HUB (150 МБ Electron программ) |

## Хэрэглэгч хэрхэн суулгах вэ

1. AULA-гийн жинхэнэ драйверыг [aulastar.com](https://www.aulastar.com/keyboard/)-оос
   татаж суулгана.
2. Загвартаа тохирох `_mn.zip`-ийг задалж, **`install-mn.bat`** дээр хоёр товшино.
   Администратор эрх асуувал зөвшөөрнө.
3. Драйверыг нээгээд **Config → Language → Монгол**.

Скрипт нь суулгасан драйверыг өөрөө хайж олдог, `Cfg.ini`-ийн нөөцийг
(`Cfg.ini.bak`) үлдээдэг тул буцаахад амархан.

---

## Багцыг дахин үүсгэх

AULA драйвераа шинэчилсэн үед:

```bash
# 1. Шинэ драйверуудыг installers/ дотор хийнэ
# 2. Дахин үүсгэнэ:
python tools/build.py installers/*.exe
```

Шаардлага: [innoextract](https://constexpr.org/innoextract/)

```bash
winget install --id dscharrer.innoextract -e
```

`build.py` нь загвар бүрийн `text.xml`-ийг уншиж, тухайн загварын
түлхүүрүүдээр монгол файл үүсгэнэ. Хэрэв AULA шинэ мөр нэмсэн бол
анхааруулаад тэр мөрийг түр англиар үлдээнэ.

### Орчуулга засах

Бүх текст **`tools/mn.json`** дотор байна. Засаад `build.py`-г дахин
ажиллуулна.

Зарим түлхүүр загвараас хамаарч өөр утгатай байдаг (жишээ нь `tc_ms23` нь
F75 дээр *Debounce*, F108 дээр *Notify*). Эдгээрийг `_overrides` хэсэгт
`"түлхүүр|англи текст"` хэлбэрээр зааж өгсөн.

## Файлын бүтэц

```
tools/
  mn.json             ← монгол орчуулга (энд засвар хийнэ)
  build.py            багц үүсгэх
  inspect_driver.py   драйвер хэлээ хэрхэн ачаалдгийг шалгах
pack/
  install-mn.ps1      суулгах скрипт
  install-mn.bat      түүнийг ажиллуулах
dist/
  <ЗАГВАР>_mn.zip     хэрэглэгчид өгөх багц
installers/           AULA-гийн драйверууд (git-д ордоггүй)
```

## Шалгагдсан ба шалгагдаагүй зүйл

**Шалгасан:**
- Дөрвөн загварын `text.xml` нь эх файлтай яг ижил түлхүүртэй, ижил дараалалтай
- UTF-16 LE + BOM, CRLF — эх файлын формат хэвээр
- Хоосон мөрүүд хоосноороо үлдсэн
- Орчуулагдаагүй мөр **байхгүй** (218–272 кирилл мөр загвар тус бүрд)
- `Cfg.ini` засвар: Title, Appdir зэрэг бусад тохиргоо хэвээр, кодчилол зөв

**Шалгаагүй — жинхэнэ гар дээр туршина уу:**
- Драйвер монгол текстийг дэлгэц дээр хэрхэн харуулах (фонт, урт мөр багтах эсэх)
- `Config → Language` цэсэнд "Монгол" гарч ирэх эсэх

Эдгээрийг зөвхөн жинхэнэ гар залгасан компьютер дээр шалгаж болно.

## Эрх зүйн тайлбар

Энэ бол AULA-гийн драйверт **нэмэлт хэлний файл** бөгөөд драйверын
программыг өөрчлөөгүй. Драйвер өөрөө AULA-гийнх — хэрэглэгч түүнийг
AULA-гийн албан ёсны сайтаас татаж суулгана. Асуудал гарвал AULA-тай
холбогдоно уу.
